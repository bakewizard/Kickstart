# Kickstart theme for [BakeKit CMS](https://github.com/bakewizard/bakekit)

## Features

- Bootstrap 5 based responsive layout
- Built-in support for Pages and Articles
- SEO-friendly meta integration
- SCSS structure and Gulp setup for easy asset management
- Developer-friendly and easily extendable

## Installation

You can install this theme via the BakeKit Admin Panel by uploading the theme zip.
